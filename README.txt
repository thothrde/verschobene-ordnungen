VERSCHOBENE ORDNUNGEN — Bilder, Nachbilder, zweite Lesarten — v0.7

Autostart: ja. Die Sequenz startet automatisch ohne Klick.
Steuerung:
  Leertaste = Pause / Weiter
  Pfeil links/rechts = Szene wechseln
  P = Provenienz ein/aus

Änderungen in v0.7:
  - Untertitel ohne wertende oder werbliche Formulierungen
  - kurze, indirekte Zwischentitel vor den jeweils folgenden Bildgruppen
  - keine Zitate aus fremden oder eigenen Texten
  - Szenen mit mehr als zwei Bildern laufen länger als Einzel- und Doppelszenen

Inhalt:
  66 Fotografien aus Photocollection, Photoblog, Manhattan und OWL.

Die Bilder werden direkt von den öffentlichen Originaldateien auf stumbleduponthis.de geladen;
daher ist Internetzugang nötig.
